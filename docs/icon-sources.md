# Icon sources

Product logos come from [Devicon](https://github.com/devicons/devicon) (MIT) and [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0). Brand names and marks belong to their respective owners.

The original logo paths are preserved, with padding and a warm cream tile added for readability on dark and light GitHub themes. Simple Icons marks use brand blue for Google Apps Script and dark brown for MicroPython. Icons are stored locally; no image service is required to display the tech stack.
