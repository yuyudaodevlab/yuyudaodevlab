# Profile design

The profile uses a warm dark-brown background, muted caramel accents, and cream text. The header centers the `yuyudaodevlab` name beside an original coffee illustration. Steam moves gently; reduced-motion preferences disable animation.

Technology logos are shown as individual icons in short labeled groups. The bio and activity details remain regular Markdown text. The footer is a small illustration with a brief thank-you.

The GitHub activity card shows a dated snapshot of public repositories, stars, and followers. The local generator reads GitHub's public API and writes the SVG; see [profile maintenance](profile-maintenance.md).
